# Demo Records

This folder stores example outputs generated while testing the `engineer-post-writer` Skill.

Each demo record should be saved as a Markdown file so people browsing the GitHub repository can see how the Skill behaves with real engineering notes.

## Naming Rule

Use this format:

```text
name_YYYY-MM-DD.md
```

Examples:

```text
rust-json-log-cli_2026-05-01.md
ai-coding-workflow_2026-05-01.md
open-source-release_2026-05-01.md
```

## Recommended Record Format

Each record should include:

- Source material or rough notes.
- Signature setting, including no-signature cases.
- Generated LinkedIn post.
- Generated Threads post.
- Notes about whether the output matched the Skill rules.
